## Criterios de aceptación
Historia 2: Como bibliotecario, quiero registrar los préstamos para saber quien tiene cada libro.

1. Bibliotecario intenta registrar un préstamo.
2. Existen libros disponibles para prestar?
3. Si la cantidad es > 0, se resta un ejemplar al total disponible y se guarda el préstamo con el nombre del socio, el ejemplar y la fecha de préstamo.
4. Si la cantidad es < 0, se muestra el mensaje: "No hay ejemplares disponibles".

**Criterio 1**:
**Dado** que bibliotecario intenta registrar un préstamo
**Cuando** la cantidad es < 0
**Entonces** se muestra el mensaje "No hay ejemplares disponibles"

**Criterio 2**:
**Dado** que bibliotecario intenta registrar un préstamo
**Cuando** no introduce el nombre del socio
**Entonces** se muestra el mensaje de error "Introduce un nombre de socio válido"

**Criterio 3**:
**Dado** que bibliotecario intenta registrar un préstamo
**Cuando** todos los campos son rellenados correctamente y hay ejemplares disponibles
**Entonces** se muestra el mensaje "Préstamo realizado correctamente"
