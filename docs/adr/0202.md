1. Iteración 1: Funcionalidades básicas

Driver: Diseña la tarjeta Artículo
┌─────────────────────────────────────────────────┐
│ Clase: Artículo                                 │
├────────────────────────┬────────────────────────┤
│ Responsabilidades         Colaboradores         │
├────────────────────────┼────────────────────────┤
│ Conocer nombre         │      -                 │
│ Conocer precio         │      -                 │
└────────────────────────┴────────────────────────┘
Navigator: Revisa la tarjeta. Artículo no necesita colaboradores ya que solo guarda los datos.

Driver: Diseña la tarjeta Carrito
┌──────────────────────────────────────────────────────────┐
│ Clase: Carrito                                           │
├─────────────────────────────────┬────────────────────────┤
│ Responsabilidades                  Colaboradores         │
├─────────────────────────────────┼────────────────────────┤
│ Añadir artículos                │      Artículo          │
│ Calcular el precio total        │      Artículo          │
| Conocer cuantos artículos tiene |      Artículo          |
└─────────────────────────────────┴────────────────────────┘
Navigator: Revisa la tarjeta. Carrito colabora con Artículo ya que para añadirlos o calcular el precio tiene que preguntarselo a la clase artículo.

Casos de prueba:
- Caso 1: El carrito está vacío y su precio es 0.
- Caso 2: Se añade un artículo al carrito y el precio es correcto.
- Caso 3: Si se añaden más de un artículo, el precio debería ser la suma de ambos.
- Caso 4: Cuando se añaden artículos, el carrito muestra la cantidad de artículos que hay en él.

2. Iteración 2: Tras la "revisión del cliente"

Tras la revisión del cliente se añaden 2 funcionalidades nuevas: Eliminar artículos del carrito y calcular descuentos porcentuales aplicados al conjunto.

Driver: Añade los cambios a la tarjeta correspondiente (iría sustituido en la tarjeta anterior pero la dejo aquí para que se vean las modificaciones con fines de facilitar la corrección)
